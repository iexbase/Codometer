The first public release of Codometer — a native macOS app that keeps your **Claude Code** and **Codex** limits,
and the agents working for you, one glance away.

Everything it shows is read from files the two CLIs already write on your Mac. Nothing is uploaded, no account is
switched for you, and no limit is worked around.

## What's in it

- **The island** at any screen edge: one ring per limit, expanding into a card with the main window's chart, tiles
  for the other windows and the live agent sessions. It snaps, fuses with the camera notch, and closes on Esc even
  while another app is in front.
- **A floating card** as the other way to show the same thing — drop it anywhere, four themes, two sizes,
  double-click to shrink it to a pill.
- **The strip** — a wide bar with what’s left and every limit side by side, for one account, all Claude, all Codex
  or everything.
- **Essentials first**: the island opens on just the limits — used, left, reset. The chart and sessions are one
  setting away.
- **The menu bar** with a live ring and the same card in a popover, whichever style you chose.
- **Desktop widgets**: “AI Limits” in three sizes, “Claude” and “Codex” in two, and a strip version of each.
- **Several accounts** (one profile folder each), groups with their own notification switches, and a guided way to
  add a second account.
- **Notifications** for thresholds, resets, “agent finished” and “agent is waiting for you” — replaced in place,
  grouped when they arrive together, withdrawn once the agent continues.
- **Timeline and “Who used the limit”** over 5 hours, 24 hours or 7 days.
- **English and Russian**, English by default, switched in Settings without a restart.
- **Data controls**: history retention, export to JSON or CSV, and a two-step erase that says exactly what goes and
  what stays.
- **Diagnostics** with a system check, per-account refresh history and locally kept crash reports.
- **Energy-aware refreshes** on battery, in Low Power Mode and when the Mac runs hot.
- **Service status** from the providers' public status pages — opt-in, off by default, and the only network access
  in the app.

## Requirements

macOS 26 (Tahoe) or later, Apple silicon, and Claude Code and/or Codex installed and signed in.

## Installing

Open the DMG and **drag Codometer to Applications** — it refuses to run from a disk image, from Downloads or from
any other volume. Check the download against `SHA256SUMS.txt` first. This build is not notarized yet, so the first
launch needs one trip through System Settings; the exact steps are right below these notes and in the README
(“Install”).

## Known issues

- Apple silicon only; no Intel build.
- Ad-hoc signed, so Gatekeeper asks once per version.
- A copy kept under `/Volumes/` (an external drive) is treated as a disk image and refuses to run.
- Widgets lag behind the island by a minute or more — WidgetKit's reload budget, by design.
- History is collected only while Codometer runs; earlier periods are shown as gaps, not filled in.
- “Who used the limit” is an estimate.
- Codex logs have no “approved” event, so an already-approved long command looks like a pending approval until its
  result arrives; after a minute the wording softens to “waiting for approval or running a command”.
- Erase reports a leftover if another program put a file in Codometer's folder (a Finder `.DS_Store`, typically).
- The technical detail lines in Diagnostics and the support report are English in both languages, on purpose.
- No auto-update and no update check.
- No license has been chosen yet, so the repository ships without a `LICENSE` file.
